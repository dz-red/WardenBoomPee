# WardenBoomPee
2-в-1 плагин для Minecraft (Paper): портативный **бумбокс** + набор шуточных эмоций.

## 🎵 Бумбокс
Переименуй проигрыватель (jukebox) в наковальне в «Бумбокс» — откроется меню, куда можно сложить пластинки и **носить музыку с собой «в дорогу».**
- Поддержка **CustomDiscs** (кастомные пластинки)
- Инвентарь-меню для треков

## 😄 Эмоции
Шуточные команды: `/poop`, `/pee`, `/fart`, `/vomit` — анимации и звуки. Без гриферства.

## Сборка
`mvn clean package` (JDK 21)

## Стек
`Java 21` · `Paper API` · `CustomDiscs API` · `Maven`
